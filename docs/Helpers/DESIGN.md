# Design direction

## Settlement sheet

The public surface treats transaction integrity like a legible clearing-house record: a dark ledger ground, quiet registration lines, amber action marks, and green verification states. The landing page is not a generic fintech dashboard; it is a single transfer narrative that makes the product's mechanism visible.

- Use warm near-black surfaces with restrained olive-green and ledger-amber accents.
- Use compact mono labels only for actual records, status, and identifiers.
- Let one continuous route line carry the hero composition.
- Keep actions direct and rectangular; avoid pill-heavy UI.
- Use verification marks and history language only where the product behavior supports them.
- Preserve high-contrast focus states and stack the ledger composition on small screens.
